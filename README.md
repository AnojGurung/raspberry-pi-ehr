#Raspberry Pi EHR Monitoring System
A python and raspberry pi based Electronic Health Record prototype.

## Current Features

- Patient Registration
- SQLite and nurse assignment
- Visit records
- Patient photo capture
- RFID patient identification
- Pulse monitoring
- Temperature monitoring
- Automated vital sign logging
- Pandas Analysis
- Matplotlib Visualization
- Django web interface

## Technologies
- Python
- SQLite
- Raspberry pi
- Pandas 
- Matplotlib

## Disclaimer
This project is an educational prototype and is not intended for clinical diagnosis or real-world medical use.
