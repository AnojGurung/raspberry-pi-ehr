# Raspberry Pi EHR Monitoring System

A Python and Raspberry Pi-based Electronic Health Record prototype designed to manage patient information and later integrate automated vital-sign monitoring.

## Current Features

- Patient registration
- SQLite patient database
- Patient listing
- Menu-driven patient management

## In Development

- Patient search by ID
- Patient clinical profile
- Doctor assignment
- Nurse assignment
- Visit records
- Clinical notes
- Patient photo capture

## Planned Hardware Integration

- RFID-based patient identification
- Pulse monitoring
- Temperature monitoring
- Automated timestamped vital-sign recording
- LCD patient-status display

## Data Analysis

Planned analysis features include:

- Pandas-based vital-sign analysis
- Average, minimum, and maximum measurements
- Longitudinal pulse and temperature trends
- Matplotlib visualizations

## Future Development

- Django web interface
- Patient dashboard
- Doctor and nurse dashboard
- Visit scheduling
- Historical vital-sign visualization

## Technologies

- Python
- SQLite
- Raspberry Pi
- Pandas
- Matplotlib
- Django (planned)

## Hardware

Planned hardware includes:

- Raspberry Pi
- MCP3008 ADC
- Pulse sensor
- Thermistor
- RC522 RFID reader
- Raspberry Pi Camera / USB camera
- LCD display

## Project Status

Active development.

The project currently supports patient registration and retrieval from an SQLite database. Hardware-based vital-sign monitoring will be integrated incrementally.

## Disclaimer

This project is an educational prototype and is not intended for clinical diagnosis or real-world medical use.
